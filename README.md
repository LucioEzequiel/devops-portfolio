# DevOps Portfolio

Portfolio de la materia Operaciones I (UNaHur). Reúne los trabajos prácticos TP01 a TP12 del curso de DevOps, con la aplicación Notes App como hilo conductor.

## Stack tecnológico

- Docker y Docker Compose
- PostgreSQL, Flask y Nginx
- GitHub Actions para CI/CD
- Prometheus y Grafana para monitoreo
- Kubernetes con k3d, Helm y Traefik
- Terraform con provider Docker
- GitOps con GitHub Actions
- Alertas de seguridad con Prometheus y Grafana
